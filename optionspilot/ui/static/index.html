        How market data works

        Why there is more than one provider

        Free market-data feeds go down, rate-limit by IP address, and occasionally return bad numbers. One source means one bad afternoon takes your charts with it. OptionsPilot keeps a chain of providers and asks them in order — the first that answers with usable bars wins, and the rest are never contacted.

        What happens when one fails

        The failure is classified (unreachable, timed out, rate-limited, key rejected, or answered-with-unusable-data) and the next provider is asked immediately. After a few consecutive failures a provider is taken out of rotation for a cooling-off period that doubles each time, so a dead source costs one failed request rather than being retried on every chart tick. When the cooldown ends it gets exactly one probe request — recovery is automatic and never needs a restart.

        A refusal that is a correct answer to an impossible question — asking for 5-minute bars from last spring, which no free provider keeps — is not counted against a provider's health. Only genuine failures move it down the order.

        Why some providers need an API key

        Yahoo and Stooq are open endpoints. Finnhub, Twelve Data and Alpha Vantage require you to register — free, no card — and issue a key that identifies your requests so they can meter them. Nothing here costs money; the keys exist so the provider can enforce a free tier.

        Your keys never leave this machine. They are stored in a separate file with owner-only permissions, shown only as ••••••••abcd, and are stripped from every diagnostics export, report and log line — so a bug report is always safe to share.

        Why Yahoo is first

        It is the fastest of the free sources, needs no key, has no metered budget to spend, and reports why it refused a request rather than returning an empty result — which is what lets the app tell "there is no data" apart from "I could not reach the data". That distinction is the difference between a chart that explains itself and one that is silently blank.

        Yahoo and yfinance are two independent pieces of code reaching the same servers, so they do not protect you from a Yahoo outage. Adding one keyed provider is what buys a genuinely independent source.

        The words on this page

        Unlimited
        No published request budget. Fair use still applies — sustained hammering can get an IP throttled.
        Rate limited
        A published allowance per minute and/or per day. The app counts requests before sending them and stops asking once the budget is spent, so you get a clear explanation instead of a wall of errors.
        Paid
        Not used here. Every provider in this build runs on its free tier; a paid plan only raises the numbers under Budget.
        Real-time
        Prices as they trade. None of the free tiers offer this for US equities.
        Delayed (poll-only)
        Prices lag the market (typically 15 minutes) and arrive only when the app asks for them, rather than being streamed. This is why the forming candle updates on a timer.
